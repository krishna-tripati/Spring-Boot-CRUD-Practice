This repository contains a collection of hands-on projects developed while learning Java Spring Boot and Spring Data JPA.  <br>

The main objective of these projects is to understand backend development concepts, implement CRUD operations, build REST APIs, and learn how to integrate Spring Boot applications with databases. <br>
<br>
🚀 Projects Included  <br>

1. Student Management System  <br>

Perform CRUD operations on student records. <br>

Add, view, update, and delete student information. <br>

Practise Spring Boot REST API development. <br>

2. Product Management System <br>

Manage product information. <br>

Implement Create, Read, Update, and Delete operations. <br>

Understand REST API request handling. <br>

3. Employee Management System  <br>

Perform CRUD operations using in-memory data storage. <br>

Manage employee details. <br>

Understand basic CRUD logic without database integration. <br>

4. Product Inventory Management (With Database) <br>

Manage product inventory details. <br>
 
Implement CRUD operations. <br>

Practise database integration using Spring Data JPA. <br>

5. Employee Management System (With Database) <br>

Manage employee records using database integration. <br>

Implement CRUD operations using Spring Boot and Spring Data JPA. <br>

Practise entity and repository concepts. <br> 

🛠️ Technologies Used  <br> 

Java, Spring Boot, Spring Data JPA, Hibernate, MySQL, Maven, REST APIs, Postman, IntelliJ IDEA  <br>

📚 Concepts Learned <br>

Spring Boot project structure <br>
RESTful API development <br>
HTTP methods (GET, POST, PUT, DELETE) <br>
CRUD operations <br>
Controller, Service, and Repository layers <br>
Dependency Injection <br>
Spring Data JPA <br>
Entity mapping and ORM concepts <br> 
Database connectivity <br>
Maven dependency management <br>

🎯 Learning Objective  <br>

These projects are developed for learning and practising Spring Boot backend development. Each project helped me improve my understanding of REST APIs, CRUD functionality, application architecture, and database operations.
